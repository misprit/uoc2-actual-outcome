## What this repository does and does not contain

This repository contains **only** release packages and documentation written
for this project.

It does **not** contain the original game files. The release packages contain:

* files **added** by this mod (its own helper modules and its own localisation
  and UI resource fragments), and
* files **modified** by this mod, which are derived from the game files that
  the player already has installed.

No file in a release package is byte-for-byte identical to an unmodified
original game file. To use the mod you must own the game; the mod is applied
to your own installation.

## Installation footprint

Installing this mod **replaces eight original game files and adds seven new
files** inside your game installation. Both operations are fully reversible:
restore the eight originals (from your own backups or with Steam's *Verify
integrity of game files*) and delete the seven added files. The full list is
documented in the installation guide shipped with every release.
